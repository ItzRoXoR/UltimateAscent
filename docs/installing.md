# Installing

[Ultimate Ascent](../README.md) documentation.

Copy `UltimateAscent.dll` into `BepInEx/plugins/UltimateAscent/` of your r2modman profile (or the
game folder), or import the packaged zip in r2modman. Requires BepInExPack for PEAK. The Builder maps are a
separate zip (optional; they need True Final Ascent): import it in r2modman too, or put its BuilderMaps folder
anywhere under `BepInEx/plugins`.
